### 關鍵技術亮點：
1. **Grounded 雙軌比對機制**：徹底解決了傳統 ASR 在深奧佛學（中觀應成、因明自證、二諦抉擇）上大量出現同音錯字的問題。
2. **同音歧義負向約束正則**：例如自動生成 `(?<![初二三四五六七八九十])世俗[地第]`，既精準校正錯字，又 100% 保護了「菩薩十地」的正常論述。
3. **極致效能調優**：
   - 批次量從 12 句調整至 25 句，減少 57% 的 LLM 呼叫次數。
   - 接入 Port 8010 專屬 GPU Whisper 容器，將音訊轉寫速度提升 5 倍。

## 🛠️ 五、 維運手冊與實用指令速查

為便於後續日常維護與持續進化，專案已建立標準 npm 指令集：

```bash

npm run learn:dry-run

npm run learn:sync

# 7. 本地預覽：啟動本地 Web 閱讀器伺服器
```
