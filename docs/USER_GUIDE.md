## 🌟 五大核心亮點功能

### 1. 🎵 隨點即聽・音文同步高亮
* **點擊發聲 (Click-to-Seek)**：在逐字稿中點擊任何一句話或時間標籤，錄音立刻精確跳轉到該處開始播放。
* **自動跟隨 (Auto-Scroll)**：音訊播放時，當前朗讀的句子會自動亮起溫潤的黃金底色，畫面自動平滑滾動，無需手動翻頁。
* **貼心閱讀保護**：當您主動用手指或滑鼠滑動頁面查閱前文時，系統會智慧暫停自動滾動，絕不干擾您的閱讀思考。

### 2. 📑 宗大師科判樹・階層導航
* 結合原典章節目錄，左側與內文上方皆提供階層化的 **【科判導讀卡片】**。
* 每張卡片清晰標注了宗大師科判標題、對應的 **課本頁碼（如 `p.159`）** 與 **錄音時間**，讓您隨時清楚當前開示處於整部大論的哪一個正理脈絡中。

### 3. 🔍 全文關鍵字檢索與名相速查
* 頂部搜尋框支援即時全文檢索（如搜尋「補特伽羅」、「勝義諦」、「自相有」）。
* 點擊搜尋結果即可一鍵跳轉到該堂課、該段落並同步播放錄音。

### 4. 💡 雙擊編輯・研讀筆記與文字校勘
* **雙擊句子進入筆記**：在閱讀過程中，**滑鼠雙擊任何句子**（或手機長按），即可彈出筆記與校對視窗。
* **記錄心得**：可選擇標籤（如【重點標記】、【法義疑問】、【經典出處】），並輸入您的研讀筆記。
* **一鍵匯出筆記**：點擊頂部 **【📥 匯出筆記】** 按鈕，即可將整堂課的所有心得、標記與校對紀錄下載為精美的 Markdown 筆記文件！

### 5. ⭐ 1～10 分線上 Review 評分與改進工單
* 頂部工具列提供 **【⭐ 講次審核 (1~10分)】** 按鈕。
* 若您在試聽過程中覺得某講次品質優良，可評 8～10 分；若發現任何名相或時間戳問題（評分 $<8$ 分），系統會自動生成 **【待改善工單】**，由 AI Agent 啟動深度二次精校！

## 🚀 快速上手教學（三分鐘學會）

### 步驟一：選擇您想研讀的講次
點擊左上方 **【☰ 目錄】**，從側邊欄清單中選擇講次（例如點選 `第 80A 堂 | 2018-04-07 | p.249`）。

### 步驟二：開始聽講與閱讀
* 點擊底部播放器的 **【▶️ 播放】** 按鈕開始聆聽。
* 也可以直接在逐字稿中 **點擊任何一句感興趣的話**，音訊就會立刻從該句開始發聲！

### 步驟三：客製化閱讀舒適度
* **字體縮放**：點擊頂部的 **【A-】** 與 **【A+】** 可自由調整字體大小（70% ～ 150%）。
* **深色模式**：夜間研讀時，點擊右上角 **【🌙 深色模式】**，即可切換為護眼的暗色背景與柔和字體。

### 步驟四：記錄筆記與校對
1. 在任何句子上 **連點兩下滑鼠（雙擊）**。
2. 彈出對話框後，您可以：
   * 在「研讀筆記」欄位寫下法師的精闢開示與個人體悟。
   * 若發現錯字，可在「修改後文字」欄位進行訂正。
3. 點擊 **【💾 儲存】**，該句子旁邊將會出現專屬的筆記標記圖示。
4. 點擊頂部 **【📥 匯出筆記】**，一鍵下載整堂課的完整筆記報告！
