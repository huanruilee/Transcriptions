# 單趟佛法逐字稿校訂與分段規範（One-Pass v2）

輸入資料格式為 `行號|起始秒-結束秒|Whisper原始ASR`（已直接附於本次訊息中）。**不要讀取任何其他專案檔或執行任何工具**，直接一次性完成校訂並**僅輸出**校訂後的純文字結果（不要加 Markdown code fence ` ``` ` 或任何前後說明）。

## 一、固定編校紅線
1. **臺灣繁體中文正字與出版級標點**：統一使用全形標點（`「」`、`『』`、`，、；：。？！`），**嚴禁使用英文彎引號 `“”‘’` 或任何簡體字**。每句結尾必須有全形句尾標點（`。？！；`）。
2. **合併碎句與清除純冗詞**：
   - 把被 ASR 切碎的 1～3 字短句與換氣斷句依語意合併為自然完整句子，確保全講 1～3 字孤立碎句比例 `< 2.0%`。
   - 徹底清除 `呃/嗯/啊/喔` 等無實義發語詞與結巴重複；**僅含純發語詞／空白之無意義短行（如單獨的 `嗯`、`啊`、`好`）請直接跳過不輸出**。
   - **完整保留實義連詞／副詞（`因為/所以/如果/但是/已經/不要`）、開場三稱「南無本師釋迦牟尼佛」與開經偈、結尾迴向偈**；不得整段改寫或捏造未講內容。
3. **講者判別與學員去識別化（嚴格零漏網）**：
   - `@PARA speaker=...` 欄位**僅允許固定枚舉值**：`主持`、`學員`、或本課指導法師尊稱（如 `如性法師`）。**嚴禁將 `學員1`、`學員2` 寫入 `speaker=` 欄位**（編號匿名僅用於內文對話提及學員姓名時）。
   - **開場領眾**（問候法師與同學、請大家合掌、三稱「南無本師釋迦牟尼佛」與「開經偈」）與**結尾收攝迴向**之 `speaker` 一律標為 `主持`，**不可標為 `學員` 或法師**。
   - **嚴禁保留任何學員真實姓名／私稱／XX師姐／XX師兄**（例如 `謝謝王小明`、`請陳師姐`、`林師兄` 等，哪怕只有姓氏或單名帶稱謂），一律匿名改為 `學員1`、`學員2`……（一般無姓氏泛稱 `各位師兄`、`各位師姐`、`謝謝法師`、`謝謝主持` 可保留）。
4. **自然段與小標節流**：
   - 依語意與講者輪次切為 **8～20 句的自然段**（**單段硬上限 35 句**），不可 1～3 句就斷成一堆碎段。
   - **僅在重要話題大轉換處**加精煉小標（`<= 35` 字），例如 `heading=〔提綱一：佛法大海，信為能入〕`；整場 2 小時課程目標約 **10～30 個小標**，**不要每一段都加 `heading=`**。
