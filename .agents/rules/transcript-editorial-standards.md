# 逐字稿編輯與閱讀品質紅線清單

完整流程與版本紀錄以 [docs/TRANSCRIPTION_WORKFLOW.md](../../docs/TRANSCRIPTION_WORKFLOW.md)（SSOT）為準；以下為所有課程共通之必檢項目：

- **禁止**：整段改寫、濃縮成大綱摘要、刪除實義副詞／邏輯連詞（`剛好`、`已經`、`因為`、`所以`、`如果`、`但是`、`沒有`、`不要`）、捏造未講內容，或破壞 `sentences[].rawText`。
- **強制**：
  1. **區分「修辭重複」與「口語冗詞／結巴」**：保留講者刻意強調的修辭重複；徹底清除發語詞（`呃`、`嗯`、`啊`、`喔`、`欸`）、句首無實義過渡詞（`好，那`、`那，`、`好，`、`就是說，`）與口吃結巴重複（`這個這個`、`然後，然後呢`）。整句僅含冗詞或無實義單字應答時，直接移除該 `sentence` 物件（嚴禁留空字串 `""`）。
  2. **合併被 ASR 切碎的短碎片**：將 1～3 字語意未完碎片（「第一點」「例如」等）與換氣斷開的子句合併為完整分句，繼承首尾 `[start, end]` 時間軸；全講 1～3 字孤立碎句比例須 `< 2%`。
  3. **先合句校字再補出版級標點**：`rawText` 絕對不動，但 `text` 須先合併換氣斷句並依 `grounding.json` 校對同音誤辨，將半截斷句順為自然通順的句子後再補齊全形標點（無句尾標點句比例 `< 5%`）；**嚴禁以「漢字零改動守衛」跳過同音校字並直接對未合併碎行硬塞句號**。
  4. **兩級分段、自然語意段與官方 YouTube 提綱優先標準**：只要該講 YouTube 說明欄附有時間碼提綱，**直接以官方時間碼與標題作為唯一一級章節切點，停用模型自創標題**；章節內一律切分為無標題之 **150～350 字（約 8～20 句）二級自然段**（單段硬上限 35 句，標竿參照《金剛般若波羅蜜經》），**嚴禁數百句擠成巨段，亦嚴禁固定 7～8 句機械切片或過度碎段**。僅於無 YouTube 時間碼提綱時，方由科判或模型產生精煉編號小標。
  5. **單向導讀全講覆蓋與討論題收斂**：`_meta.correctionsPending` 與 `hallucinationSuspects` 清零並通過專家定稿後，才可生成／同步 `contentOverview`（四個 `evidence[]` 陣列與 `sourceDigest`）；產出主旨須先鳥瞰全講單元並依實際長度動態覆蓋中後段核心論題，打破固定 2 條模板慣性；**翻修舊講若既有 `mainPoints` 遺漏中後段核心討論題，必須重新生成導讀**，不得僅重算 `sourceDigest`。每講須區分核心討論題與課堂反覆追問，將 `discussionTopics`／`discussionQuestions` 歸併收斂為 **3～7 題**並以全形問號 `？` 結尾，**嚴禁把冗長口語發問整段貼成小標**。
  6. **全域置換與底本護欄**：執行正字／標點置換前先遮罩 `https?://...` URL（避免破壞 `watch?v=`）；具備官方底本時須先做 Unicode NFKC 正規化並執行底本專名強制對齊；保護已鎖定講次（`config/locked-sessions.json`）。
  7. **自動化門檻驗收**：交付與合併前必跑 `npm run audit:reading-quality -- courses/<課程名>`（適用「待閱校版」與定稿）。
  8. **體裁分流、角色邊界與狀態誠實標記**：開工前必備該課程 `grounding.json` 與 `COURSE_GUIDE.md`；共學／問答型課程須先區分「法師／主持人／學員」角色輪次，`teacherSummary` 僅歸納法師引導脈絡、破立邏輯與結論，不得混入學員原話或只留單句斷言。未通過 `audit:reading-quality` 前不得標記 `published` 或留空 `publicationState`，接手課程時須將「待整編歷史舊債」與「新標準講次」分軌標示處理。
