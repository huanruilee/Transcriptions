# 逐字稿編輯與閱讀品質紅線清單

完整流程與版本紀錄以 [docs/TRANSCRIPTION_WORKFLOW.md](../../docs/TRANSCRIPTION_WORKFLOW.md)（SSOT）為準；以下為所有課程共通之必檢項目：

- **禁止**：整段改寫、濃縮成大綱摘要、刪除實義副詞／邏輯連詞（`剛好`、`已經`、`因為`、`所以`、`如果`、`但是`、`沒有`、`不要`）、捏造未講內容，或破壞 `sentences[].rawText`。
- **強制**：
  1. **區分「修辭重複」與「口語冗詞／結巴」**：保留講者刻意強調的修辭重複；徹底清除發語詞（`呃`、`嗯`、`啊`、`喔`、`欸`）、句首無實義過渡詞（`好，那`、`那，`、`好，`、`就是說，`）與口吃結巴重複（`這個這個`、`然後，然後呢`）。整句僅含冗詞或無實義單字應答時，直接移除該 `sentence` 物件（嚴禁留空字串 `""`）。
  2. **合併被 ASR 切碎的短碎片**：將 1～3 字語意未完碎片（「第一點」「例如」等）與換氣斷開的子句合併為完整分句，繼承首尾 `[start, end]` 時間軸；全講 1～3 字孤立碎句比例須 `< 2%`。
  3. **依語意補順與出版級標點**：將口語半截斷句順為自然通順的句子並補齊全形標點（無句尾標點句比例 `< 5%`）。
  4. **兩級分段標準**：YouTube 提綱／科判作**一級章節**；章節內一律切分為 **150～350 字（約 8～20 句）之二級自然段**（單段硬上限 35 句），嚴禁數百句擠成一段。
  5. **單向導讀同步與討論題收斂**：`_meta.correctionsPending` 與 `hallucinationSuspects` 清零並通過專家定稿後，才可生成／同步 `contentOverview`（四個 `evidence[]` 陣列與 `sourceDigest`）；每講 `discussionTopics`／`discussionQuestions` 皆須收斂為 **3～7 題**並以全形問號 `？` 結尾。
  6. **全域置換與底本護欄**：執行正字／標點置換前先遮罩 `https?://...` URL（避免破壞 `watch?v=`）；具備官方底本時須先做 Unicode NFKC 正規化並執行底本專名強制對齊；保護已鎖定講次（`config/locked-sessions.json`）。
  7. **自動化門檻驗收**：交付與合併前必跑 `npm run audit:reading-quality -- courses/<課程名>`（適用「待閱校版」與定稿）。
