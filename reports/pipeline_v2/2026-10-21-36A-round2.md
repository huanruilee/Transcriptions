# 36A 第二輪：局部保真校對、底本對齊與獨立模型驗證

起點：`f4cddce42acf4d33bed04babd20a5b2a7b5f3e43`，延續草稿 PR #271。所有候選僅存於 `tmp/pipeline_v2/36A/round2/`。本輪沒有合併、發布、修改正式樣本、換掉既有服務或將完整模型升為預設。

## 完成的改進

1. **先統一正體，再套詞庫與比較。** 使用共享 OpenCC 正規化；繁簡差異不再被誤判為實詞改寫，亦保留「無明了」防過度轉換規則。
2. **局部提案與逐筆審查。** LLM 回傳 `before`、`after`、`occurrence`、`evidence`，由程式定位原文；也支援明確 `start`／`end`。保留歷史整句提案的相容讀取，但先拆成局部差異。座標不符、範圍重疊、刪重複、未驗證改寫與錯誤證據型別均拒絕；同句可核准的修改仍能保留。`editAudit` 保存接受／拒絕理由，不靜默重寫。
3. **T6 底本檢索與同音對齊基礎。** 從當講擴大頁窗建立跨實體行的短句索引，透過拼音／字元比對檢索候選。頁碼、行號、原句及匹配分數提供給 LLM；自動替換只接受音節完全相同、有至少五字短句上下文且具原文字符重合的對齊，保留每次重複。未把整段讀誦直接替換成原典，亦未將未確認的整句強制加引號。
4. **詞級時間戳實際接入。** 保留 runner 與服務回傳的 words；僅在詞文字完整覆蓋原段、時間有效且單調時採用詞邊界。獨立推論回傳真實 words，未捏造詞級時間。既有 8010 不支援 words 的情況仍保留原段。
5. **獨立實測與音檔綁定。** 新增一次性 CUDA runner，使用既有快取與既有容器映像，以無網路、唯讀掛載的獨立容器逐次跑完 turbo／完整 large-v3。記錄實際模型路徑、權重 SHA-256、執行版本、精度、解碼參數、詞級時間戳與音檔雜湊。`--asr-json` 只接受與指定音檔 SHA-256 相符且具有效時長／單調句段的結果。
6. **固定測試集及參考稿待聽核狀態。** 開發切片與兩段保留切片在比較前寫入版本化 fixture。產生逐句音訊與兩模型文字對照的聽核頁；模型一致不等於已聽核。`reference_verified=false`、`publication_accepted=false`，沒有自動把新稿當成正解。

全套測試曾抓到重構遺漏既有科判參考，已恢復；OpenCC 合約改為檢查共享正規化元件，並增加實際轉換行為測試。未放寬既有內容驗收。

## 實際模型比較

兩模型使用相同的 16kHz 單聲道音訊、同一份 `p.111` 動態 prompt、CUDA int8、beam 5、patience 1.2、repetition penalty 1.08、`condition_on_previous_text=False`、temperature 0.0、VAD 900ms 與 `word_timestamps=True`。現有 8010／8001 服務保留運作；LLM 仍直接使用現有 8001。

執行環境：`gx10-2887`／NVIDIA GB10，faster-whisper 1.2.1、CTranslate2 4.8.0。容器映像：`sha256:5a9d53dd67be68701dc02bcb8efb4311f6bb0b30a9635672f46064f179a3041f`。六次獨立推論均成功，且均有非空 words。精確權重雜湊及每段聲學結果的雜湊見機器證據。

舊版為 `44a23af22c4dc504cc40fbe78b9a5c28ea1e7b96` 的原始程式。開發段若既有基準結果及音檔均與上一輪雜湊一致則重用；缺少快取時重新執行舊版。保留段的舊版則重新經 8010 與 8001 實跑。獨立 turbo 與完整模型使用相同新解碼參數，便於直接比較；舊版服務參數與獨立 runner 並非完全相同，不能把整個差異都歸因於模型大小。

## 固定切片與參考稿邊界

| 切片 | 時間範圍（原音檔秒數） | 用途 |
|---|---|---|
| development | 0–330.18 | 開發：開場原典、口語、重複、自我修正 |
| heldout_dialogue | 927.43–993.37 | 保留：格西／學員問答、讀誦斷句核對 |
| heldout_recitation | 2430.15–2496.55 | 保留：原典讀誦與講解 |

CER 仍按已發布 `verbatim_36A.json` 中完整落於區間的句子評估，NFC、小寫、去空白與標點，保留實詞、重複與語氣詞；假說先用相同 OpenCC 轉正體。**這是對已發布參考稿的比較，尚非對人工聽核真值的最終準確率。**

開場參考稿與多組 ASR 的措辭差異，以及問答稿中嵌入的「格西／學員」括號標記，都是需要聽核的項目；本輪沒有逕自刪掉這些內容以降低 CER，也沒有依新模型輸出改寫黃金稿。問答段的自動講者辨識亦未驗收，不宣稱學員標註已正確。

## 重現與聽核

```bash
python3 -m venv /tmp/pipeline-v2-env
/tmp/pipeline-v2-env/bin/pip install -r scripts/requirements-pipeline-v2.txt

# 在另一個終端保留本機 tunnel；測試完關閉自己建立的連線。
ssh -N -o ExitOnForwardFailure=yes \
  -L 18010:127.0.0.1:8010 -L 18001:127.0.0.1:8001 gx10

WHISPER_GPU_URL=http://127.0.0.1:18010/v1/audio/transcriptions \
VLLM_FALLBACK_URL=http://127.0.0.1:18001/v1/chat/completions \
/tmp/pipeline-v2-env/bin/python scripts/evaluate_pipeline_edits.py \
  --run-dir tmp/pipeline_v2/36A/round2
```

輸入準備：原音檔由 `audio_map.json` 的 36A 官方網址取得，依 fixture 範圍用 ffmpeg 切成 `inputs/development.wav`、`inputs/heldout_dialogue.wav`、`inputs/heldout_recitation.wav`（16kHz、單聲道）。`inputs/prompt.txt` 由 `scripts/lib/session_prompt.py::build_initial_prompt('p.111')` 產生。獨立 ASR 原始 JSON 分別為 `isolated/{turbo,large-v3}-{clip}.json`，由新增 runner 執行，例如在一次性容器中：

```bash
python3 /inputs/benchmark_whisper_isolated.py \
  --model-path /root/.cache/huggingface/hub/models--Systran--faster-whisper-large-v3/snapshots/edaa852ec7e145841d8ffdb056a99866b5f0a478 \
  --audio /inputs/development.wav --prompt-file /inputs/prompt.txt \
  --compute-type int8 --vad 900
```

容器使用上述已存在映像，以 `--network none --gpus all --read-only --tmpfs /tmp:rw,size=512m` 啟動；模型快取及 inputs 以唯讀掛載，runner JSON stdout 存回本地沙盒。模型路徑須換成現場實際存在的快取，不觸發下載或重啟正式服務。

聽核頁：`tmp/pipeline_v2/36A/round2/evaluation/reference_review.html`。狀態與音訊雜湊：同目錄 `reference_review.json`。所有 23 句均保持待聽核，尚無人工核定結果；需逐句聽音保留原話，再建立獨立已核定參考集。T7、37A／37B 發布及全講品質驗收尚未進行。

技術 API 依據：[pypinyin 官方使用說明](https://pypinyin.readthedocs.io/zh-cn/master/usage.html)、[faster-whisper 官方用法](https://github.com/SYSTRAN/faster-whisper#usage)。

## 最終實測結果

| 切片 | 版本 | 舊版 CER | 本輪 CER | 較舊版相對下降 |
|---|---|---:|---:|---:|
| development | service-replay | 24.81% | 27.25% | -9.87% |
| development | turbo | 24.81% | 28.36% | -14.35% |
| development | large-v3 | 24.81% | 25.81% | -4.04% |
| heldout_dialogue | turbo | 23.11% | 22.64% | 2.04% |
| heldout_dialogue | large-v3 | 23.11% | 17.92% | 22.45% |
| heldout_recitation | turbo | 15.76% | 16.85% | -6.90% |
| heldout_recitation | large-v3 | 15.76% | 51.09% | -224.14% |

`service-replay` 使用上一輪 VAD 900ms 完全相同 ASR 文字，僅重跑後處理：CER 從上一輪 27.92% 降為 27.25%，約改善 2.39%；仍比舊流水線 24.81% 差。此項可隔離後處理改動，不與更換模型混算。

完整 large-v3 在問答段有 22.45% 相對改善，但原典保留段嚴重退步。其句段在切片 14.49–35.48 秒之間出現 20.99 秒輸出缺口，其中 18.03 秒落在 turbo 句段覆蓋內；這是 ASR 缺漏疑慮，需要回聽，不可用底本或 LLM 補寫缺失內容。故不升為預設、不宣稱模型較大就較好。

**所有組別都未達下降至少 40% 的目標。** 這組切片證據不能支持全講或下一講發布。保留段未用來新增詞庫或修改其參考稿；全部探索／驗證輪次另存沙盒，不挑選較好輪次。

最終五項驗收均通過：`npm run test:v2` 97；`npm test` 578 通過、4 項既有略過、0 失敗；`npm run summaries:audit` 301/301；黃金標準 8/8；`npm run build:v2` 通過。Python 行為測試 24/24（本輪 13、既有 11）。CI 另安裝固定的流水線測試依賴，保證繁簡與拼音測試實際執行。七組候選逐字稿均零簡體字、零禁止同音錯字；八個已發布檔案雜湊一致。
